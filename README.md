One original pickup line, at most 200 characters, spoken by a vending machine: fully stocked, exact change only, and unlike the chips in C2 it never gets stuck when it is time to drop for you.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
